# 来源、引用与版权清单

项目原创代码、文档与示范资源使用 [MIT 许可证](../LICENSE)。第三方依赖、引用资料和外部链接指向的内容仍适用各自的许可证或授权条件。

## 本包资产

- `design/参考设计图/`：用于视觉研究的生成式概念稿；其中的仿真与成绩数据仅为构图示意。
- `design/实际运行截图/` 和 `design/工程化运行截图/`：分别为离线原型与工程版的实际运行截图。
- `web/assets/*.svg`：本包原创简化山景与操场场景 SVG；没有使用第三方商业 UI 截图作为网页背景。
- `web/css`, `web/js`, `api/`：本包演示源码，不包括任何商用平台源码或字体文件。
- `content/lessons`：面向产品原型编写的示范教材内容，不代表正式出版教材全文或教育主管部门认证课本。

## 产品参考，不直接复制

具体依赖引入时，逐项检查许可证版本、商业使用、署名要求与再分发条款。不得因为“代码开源”就默认原教材素材与图片可商用。第三方产品名称只用作产品设计研究参考，不代表合作或授权关系。

## 工程版教学素材

- 色阶采用 [Radix UI Colors](https://www.radix-ui.com/colors) 的浅色主题。配色值内置，运行时使用本地 CSS。上游使用 [MIT 许可证](https://github.com/radix-ui/colors/blob/main/LICENSE)，版权为 Copyright (c) 2021-2022 Modulz 和 Copyright (c) 2022-Present WorkOS。
- 汉字「山」「木」的笔顺依据教育部《通用规范汉字笔顺规范》GF 0023—2020。田字格和路径为本工程绘制。[规范原文](https://hudong.moe.gov.cn/jyb_xwfb/moe_2082/siju/yywzxxgls/ztzl_yywzgfbz/202103/t20210318_520473.html)
- 长安至天山廊道遗址使用联合国教科文组织公布的遗址中心点经纬度，工程内置点位和教学说明。连线表示选取遗址之间的相对分布。[遗址坐标与名录](https://whc.unesco.org/en/list/1442/maps)
- 社区阅览室决策为课堂虚构案例。英语听力采用设备本地语音，录音只在页面内播放。
- 水分子球棍模型使用归一化键长和实验键角，三维坐标随观察方向旋转后投影到界面。[NIST CCCBDB 水分子实验数据](https://cccbdb.nist.gov/exp2x.asp?casno=7732185)
