# UI / UX 完整设计规范 — 知境 V2

## 1. 视觉基准

这次 UI 以用户确认的 **“专业教材 + 沉浸式实验融合”** 方向为准，而非旧版四宫格 SaaS 展板。

主要视觉参考在 `design/参考设计图/`：

1. `01-互动教材阅读器.png`：**主设计基准**。深海军蓝左侧栏、冷白内容区、知识章节排版、顶部浅山水意境、右侧 AI 学伴。
2. `02-教学大纲工作台.png`：学科选择、教材元信息、层级大纲与章节状态。
3. `03-沉浸式实验室.png`：强调可用场景面积、真实参数、轨迹和分解。
4. `04-AI教材创作工作台.png`：内容块目录、中央排版编辑、右侧辅助工具。
5. `05-练习与学情分析.png`：答题与学习反馈（注意图中模拟成绩不是已实现的真实班级数据）。

`design/实际运行截图/` 包含本包代码的真实运行截图；产品工程师应先以这些截图验证骨架，再逐项贴近参考图。

## 2. 色彩与设计 Tokens

| Token | HEX | 用法 |
|---|---|---|
| `--navy` | `#25304D` | 左侧主导航 / 品牌背景 |
| `--navy-deep` | `#1D2844` | 导航深色层级 |
| `--indigo` | `#6168D5` | 选中、主按钮、滑块、核心标识 |
| `--indigo-weak` | `#ECECFF` | 选中背景 / 学科交互强调 |
| `--body` | `#F5F6FB` | 画布背景 |
| `--paper` | `#FFFFFF` | 教材纸面 / 工作台卡片 |
| `--line` | `#E7EAF3` | 细分割线 |
| `--text` | `#202B44` | 正文标题 |
| `--muted` | `#788299` | 辅助注释 |
| `--amber` | `#DA9B50` | 学习目标 / 例题提示 |
| `--green` | `#36A775` | 已完成 / 正确状态 |

主题不是统一“紫色 AI 风格”：数学采用蓝白理性图表，物理科学蓝实验舞台，化学使用球棍分子色系，语文保留纸张与文人气质，历史以地图/时间叙事，英语以角色语音内容为主，政治采用信息流程的稳重色。

## 3. Typography 与视觉要求

- 主界面：系统无衬线中文字体 `PingFang SC / Microsoft YaHei / Noto Sans CJK` 回退。
- 教材一级标题/知识段标题：使用系统宋体衬线回退 `Noto Serif CJK / Songti SC`，营造出版感。
- 公式：Cambria / Times New Roman 或专业数学渲染组件 KaTeX；禁止简单用错误 Unicode 拼接复杂公式的正式教材。
- 数值：等宽或 tabular figures 对齐，参数显示单位。
- 插图：简洁、科学严谨、来源明确；不为装饰添加假仪表盘、AI 星光、炫光边框。
- 用户无需下载/安装任何第三方字体；不得把商业字体文件加入项目包。

## 4. 栅格 / 响应式

| 区域 | 1440+ 桌面参考 | 主要交互 |
|---|---:|---|
| 全局导航 | 76 px | 5 个一级模块 |
| 大纲/内容目录 | 228–250 px | 树型导航、学习进度 |
| 中央教材 | 自适应，最小可读内容 550px | 图文、公式与互动块 |
| 右侧 AI / 辅助 | 270–298 px | 任务、笔记、问答、参数提示 |
| 顶部工具栏 | 58 px | 路径、搜索、辅助操作 |

- 1440px 以上：三栏阅读为主。
- 桌面可把阅读页右栏折叠成窄条。900px 及以下，学习面板排到教材下方，可折叠成展开入口。
- 780px 以下：简化为单列阅读+底部导航；后续正式版本应补移动抽屉和交互实验横屏适配。

## 5. 五大页面详细规范

### P01 数字教材阅读器
- 左：教材目录（可切换知识图谱）、章节进度、学科切换。
- 中：标题横幅→学习目标→概念与插图→公式→内嵌可操作实验→例题与练习。
- 右：学习面板可展开或折叠，默认打开 AI 学伴。对话区填满面板，输入框位于底部。互动任务、学习笔记使用独立标签页，切换时保留对话和输入。
- 交互：实验在正文中可操作；“沉浸实验”展开后进入 P03，返回保持参数。
- 设计底线：中央教材宽度必须优先保障，不能让 AI 对话挤压正文。

### P02 教学大纲工作台
- 左：七学科入口；中：教材名片、课时、章/节/知识点树、生成状态；右：所选节点目标与 AI 教材生成。
- 交互：导入 Markdown 大纲，选择节点，生成草稿，导出大纲。
- 后续：支持拖拽调整，课程标准映射，多教材版本对比与批量生产。

### P03 沉浸实验室
- 左：目标与步骤；中央 60%+ 面积留给实验场景；下：参数/数据/播放；右：任务、记录和导引。
- 物理：动态轨迹、物体、初速度、重力、时间、落地数据及对照。
- 数学：函数坐标网格、参数控制、实时顶点等信息。
- 实验准确性高于视觉背景：模型假设、单位、数据、计算结果对齐。

### P04 AI 教材创作工作台
- 左：块目录，可选中知识段/实验/例题；中：内容表单编辑 + 实时排版预览；右：AI 草稿、优化、质量检查、来源。
- 操作：新建块、修改、保存、导出 JSON；正式系统支持草稿/审核/发布。
- 交互统一：选中块的右侧工具要与块类型匹配（公式、互动、文段、练习）。

### P05 练习与学情
- 左：题目列表；中：题干、答题选项、解析；右：个人学习反馈与复习建议。
- 真实班级图表必须基于真实数据与权限展示；演示版不得杜撰成绩或人数。

## 6. 组件规范

- Button：primary、secondary、soft、ghost、destructive；最小可点击目标不小于 32px，教学大屏优先 40px。
- Outline Tree：最大 6 级、键盘导航、折叠、搜索、拖动（完整版本）。
- Interactive Block：标题、目标、舞台、参数、操作、实验结果、模型假设、资料来源。
- Knowledge Card：定义/解释/公式/探究/例题/风险或不确定性提示。
- AI Tutor：必须有状态标记（本地示例、真实模型、离线不可用），且不可压倒教材。
- 教学内容支持“沉浸 / 阅读”无损切换，并保持状态。

## 7. 动效与性能

- Tab 切换 120–160ms；卡片 hover 80–150ms，不使用大量视差和发光。
- 参数滑块改变后主视觉直接更新（目标 <100ms）；避免整页 React rerender。
- 物理动画应用 `requestAnimationFrame`，冻结/重置可复现。
- 对长教材正文采用独立滚动区域和章节锚点，避免大纲与 AI 栏跟随跳动。
- 控件可聚焦，使用 aria-label 和明确的错误提示；避免仅用颜色表达状态。

## 8. 视觉资源策略

参考图是图像稿，**不是可编辑 Figma 文件**。当前包使用原创 SVG 山景与场地示意，不把参考大图当网页背景。正式版本建议为各学科建立受控素材资源目录、引用来源与可用授权字段。

## 工程版对照

- 保持窄竖向导航、教材三栏、课程标题横幅和紫蓝灰白配色。现有原创山景与操场矢量资源随构建离线提供。
- 阅读器首屏展示教学目标、物理图解和可操作实验。独立实验页优先保留大舞台，再排列参数、数据、播放与实验记录。
- 大纲页按真实导入数据展示层级。创作台提供结构表单、实时渲染与版本操作。评价页仅展示实际答题与知识点记录。
- 390px 使用横向主导航、单列内容及自适应控制区。实测截图保存在 `design/工程化运行截图`。
