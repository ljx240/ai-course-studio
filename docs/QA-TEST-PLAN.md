## 待补齐的正式版质量门禁

- 最小 100% 关键计算回归数据集与科学事实审核规则。
- 教材来源可追溯性、授权检查，人工签发发布版本。
- 端到端无障碍：键盘树导航、屏幕阅读器、对比度、焦点顺序。
- 大纲十万节点与批量生成压力测试；多浏览器性能。
- LLM 上游限流、失败重试、JSON/Schema 错误恢复、Prompt Injection 风险评估。

## 工程版验收记录

- `npm run typecheck` 和 `npm run build` 通过。
- `npm run test:models` 通过斜抛、简谐振子、勾股关系、圆的切线和水分子空间几何。
- `python -m unittest discover -s tests -p test_backend.py -v` 共 12 项通过，含 DOCX、带文字层 PDF、快照、生成和动作拒绝路径。
- `python tests/run_studio_acceptance.py` 在实际 Chrome 中运行构建产物。验收使用临时数据库和本机模型协议夹具，涵盖大纲、版本、实验、判分、课堂和模型流程。无模型浏览路径未产生浏览器错误或外部网络请求。
- `design/工程化运行截图` 保存五页、数学、移动端和 1440px 课堂实拍。与参考图对照确认了布局、层级和舞台比例。界面使用本地矢量场景，创作台为结构表单，评价数据为验收实际作答。
