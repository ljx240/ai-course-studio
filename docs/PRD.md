# 产品需求文档 PRD · 知境 AI 教材与互动教学平台

## 1. 产品定位与目标

面向中小学教师、教研团队和学生的 **大纲驱动 AI 教材与沉浸式互动教学平台**。以结构化教学大纲为源头，将知识点形成可复用、可编辑、可交互、可审核和可发布的数字教材。

目标不是 AI 聊天框、普通 PPT 或视频播放器，而是将“精美教材阅读”与“专业实时交互实验”融合：平时阅读精细图文，遇到探索任务时原地操作，或切换至沉浸实验室；同一教材可由教师授课，也可供学生自主学习。

## 2. 角色

- **教师**：管理大纲，编写/生成教材，课堂演示，布置任务，审核结果。
- **教研员/审核员**：维护课程标准映射，审核知识准确性，发布版本。
- **学生**：浏览教材，操作实验，向 AI 学伴追问，完成练习。
教师和学习者在同一设备使用各教学界面。模型由本机服务配置。

│   └── 导入、编辑、选择、批量生成、版本管理

│   ├── 教材阅读 / 目录树 / 知识图谱

## 4. 核心用户故事与验收

### US-001 导入教学大纲
教师可粘贴大纲文本，系统识别章节标题层级并生成树。MVP 支持 Markdown 与文本缩进；正式版本增加 PDF、DOCX、XLSX、课标来源及人工纠错。

验收：对于 `# 第3章`、`## 3.2 平抛运动`、`### 运动分解`，解析后保留编号与父子关系；可在大纲树上选中节点。

### US-002 按目录选择课程
教师从学科、学段、教材、章节、知识点进入指定教材。可按目录搜索，看到草稿状态、课时建议、互动资源数及版本。

验收：至少七学科能选课；数学与物理完整示范可打开；其他显示明确的基础演示标签。

### US-003 由大纲生成教材
教师选中节点，设置目标年级、难度、风格、课时和互动类型，AI 按受控 DSL 生成草稿。模型产物不能直接发布。

验收：包含目标、概念、原理、示例、互动或图解、练习、总结；返回固定 Schema；错误引擎拒绝入库。当前实现本地模板与可选模型适配；多章生产队列待做。

### US-004 阅读精美交互教材
正文采用出版级排版，按知识顺序嵌入公式、可视化、动画与问题；相关实验能在阅读器内修改参数，或展开实验室。

验收：教材正文与实验共享参数状态；不依赖静态截图；符合键盘操作、基本响应式布局。

### US-005 实验交互与解释
学生调整参数、运行仿真、看轨迹和结果；教师可重置、对照、记录，并回到知识点。

验收：物理射程与公式一致，数学函数的开口、顶点变化正确，实验假设在 UI 中明确可见。

### US-006 教材编辑与审核
教师编辑内容块、预览、保存草稿、进行质量检查与 JSON 导出，审核员在正式产品中批准发布。

验收：编辑后刷新仍可保留；不执行 AI 生成的任意 JS；所有文字被安全转义。

### US-007 AI 学伴
AI 使用当前教材块及实验参数，可给出分步提示、解释、练习与追问。教师可以从工程版配置并测试一个 OpenAI 兼容的模型服务。

验收：保存后新请求使用已配置服务；重载保留配置；密钥由服务端保管。模型未配置时提供设置入口，调用失败时显示错误并保留问题。

### US-008 练习与学情
学生完成随堂练习，得到正确性和解析；正式系统累计多题、错因与知识点掌握度。

验收：演示题可判分，未答题不可提交；当前“班级分析”不可使用伪造真实数据。

## 5. 非功能性需求

- 性能：桌面交互滑块下数学/物理反馈目标在 100ms 内；动画目标 60 FPS，以设备与场景复杂度为准。
- 安全：密钥只保留服务端；AI 输出不执行脚本；正式版本 OAuth/RBAC、权限隔离与审计。
- 可用性：离线教材仍可阅读和操作，模型断开不影响基础课程。
- 教学正确性：模型假设、单位、坐标轴、方程、来源必须明确；正式发布需要人工复核。
- 设计：保持已确认的紫蓝灰白教育视觉，不加入炫光、厚重 AI 渐变和聊天优先布局。
- 资源：图像、视频、模型、第三方内容在发布前完成授权核查与引用记录。

## 6. MVP 边界与不做

单机工程版覆盖备课、教材审核发布、课堂讲解、交互实验和个人练习。大纲、版本和整册任务由 SQLite 保存，笔记和作答由当前浏览器保存。模型服务可选，教材仍需教师核对事实、公式和资料来源。
