# 功能完成状态

产品定位为单机版。大纲、教材版本和整册任务使用本机 SQLite，课堂和个人学习在同一设备上运行。

| 阶段 | 已可操作 | 待完成或待验收 |
|---|---|---|
| P0 前端工程化 | React 五个主页面、共享设计 token、教材渲染、七学科切换、实验室与阅读状态共享 | 概念图中的实景素材与复杂排版 |
| P1 大纲与版本 | Markdown、DOCX、带文字层 PDF、模型辅助大纲，层级编辑及搜索，SQLite 草稿快照、人工确认发布、发布版本阅读。独立课标和知识点映射 API | 扫描 PDF OCR 与完整课标管理界面 |
| P2 模型生成 | 单机 Provider 配置及连接测试、兼容模型调用、整册后台队列和重试、整章各小节或单节生成、单块重生成、阶段记录和审核提示 | 真实模型实测、检索引用、系统化学科事实审查 |
| P3 学科引擎 | 数学和物理各三个确定性场景。其余学科各三个互动场景，包含水分子三维球棍投影和本机英语跟读 | 全量教材资源与教研审校、复杂分子动力学、口语自动评分、完整历史时空底图 |
| P4 智能课堂 | 当前块和实验上下文、受控动作、逐步讲解、本机语音与字幕、全屏投影、追问暂停和恢复 | Windows 语音和实物麦克风验收 |
| 学习评价 | 随堂判分、答案解析、阅读进度、笔记、真实个人答题统计与知识点作答 | 题库、长期掌握度模型 |
| 离线和运行 | 本地静态工程版、原生 V0.2 入口、离线模板复制、Windows cmd 脚本 | Windows 真机、长期运行验收 |

模型协议夹具只用于验证接口行为。正式模型生成草稿仍需服务配置与教师审核。
