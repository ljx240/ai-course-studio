# 工程化开发计划与里程碑（交给 Codex / CodeAgent）

## 当前基线

仓库包含可运行原型 + 5 张视觉参考设计 + 7 学科示范数据 + FastAPI 可选 AI 适配器 + Pydantic Schema + 算法/浏览器测试。请先跑通基线，不要直接丢弃前端演示内容。

## P0：正式前端工程化（约 1–2 周，视开发资源而定）

- [x] 建 React、TypeScript 与 Vite 入口，并建立 Radix 语义色阶和设计组件。
- [x] 拆分工作区、大纲树、教材阅读、实验室、创作台、练习和学伴。
- [x] 建立 Lesson TypeScript 契约和 `lesson.schema.json` 驱动的运行时校验。
- [x] 分离学科计算、实验状态和场景渲染，保留原生数值模型。
- [x] 建 Playwright 浏览器验收和截图，按五张设计图核对界面。

**验收**：主导航五个页面可访问、三栏布局符合视觉基准、数学物理示范运行，浏览器无运行错误。

## P1：教学大纲与教材版本系统（约 2–3 周）

- [x] 使用 SQLite 建模课程大纲、教材版本和知识点映射。
- [ ] 大纲导入支持 Markdown / DOCX / PDF；支持纠错、树层级调整和节点选择。
- [ ] 建多教材版本、草稿状态、章节生成任务、导入导出 JSON。
- [ ] 编辑器接入 Tiptap/ProseMirror 内容块；实现自动保存与版本差异。

**验收**：导入一章大纲 → 选择一个知识点 → 建立可编辑教材 → 保存并重新打开同一版本。

## P2：AI 教材工厂（约 2–4 周）

- [ ] 在后端建立 `Parse → Plan → Draft → TemplateMatch → Validate → Review → Publish` Pipeline。
- [ ] 增加专业检索和来源链接、学科校验器、审核结果与重生成某一块。
- [ ] 对 NewAPI/OpenAI-compatible 等上游增加超时/错误分类、限流、重试和日志；生产环境不暴露密钥。
- [x] 整册后台队列、生成进度和失败重试。
- [ ] 模型调用成本记录。

**验收**：给定教学大纲，可生成一节完整草稿；所有内容块通过 Schema；教师能修订后发布，具备来源与版本审计。

## P3：学科专属引擎（建议并行迭代，4–8 周以上）

- [ ] 数学：JSXGraph + KaTeX + MathLive + Python SymPy 计算服务。
- [ ] 物理：Three.js + Matter.js 等，增加 3 种常用实验与数据联动。
- [ ] 化学：3Dmol.js 分子模型与安全虚拟实验。
- [ ] 英语：完整对话、TTS/ASR、练习反馈。
- [ ] 语文：诗词意境、汉字笔顺、文章批注。
- [ ] 历史：真实时空地图、来源验证、人物/事件关系。
- [ ] 政治：有来源和时效性的制度/法律流程场景。

**验收**：每学科至少 3 个高质量可复用模板和一节经审校完整教材；新增课程无需重建通用布局。

## P4：AI 教师与课堂学习闭环（约 3–6 周以上）

- [ ] AI 只调用受控教材/场景动作，不执行模型生成代码。
- [ ] 语音讲解、字幕和场景时间轴同步；允许暂停、追问、重新演示、继续课堂。
- [ ] 学生练习与真实学习记录（权限、数据生命周期）。
- [x] 本机课堂讲解、全屏投影、学伴问答与共享实验状态。
- [ ] 视频或离线课件导出。

**验收**：同一章节支持教材阅读、交互实验、AI 辅助讲解与教师授课四种方式，共享相同教材与场景状态。

## 工程质量检查关卡

- 使用真实浏览器比较参考图与运行时截图；视觉偏差需有明确解释。
- 任意学科插件须通过接口一致性、Schema、模型边界、无损状态恢复等测试。
- 教材发布前需至少完成公式和实例复核、来源与授权检查、人工审核签字。
- 任何班级统计、学生成绩、AI 模型输出和任务完成状态不允许伪造。

### 单机整册验收结果

- 整册任务可从课程大纲或创作台回看，逐节显示状态。成功后在同一 SQLite 事务保存草稿和目录链接。失败可重试，冲突保留已生成草稿供下载。
- 后端 14 项通过。新增用例覆盖已有生成结果恢复、失败小节重试及修订冲突保护。
- Chrome 关闭任务提交页后，在新会话重新打开任务并取回草稿。独立测试实际重启 FastAPI，已完成的第一节复用，处理中断的第二节重新生成，两个草稿一起保存。
- macOS Chrome 的本地中文语音在静音模式下通过播放、暂停、继续和完成事件验证。真实 NewAPI、Windows 真机和实物麦克风待相应环境验收。

## 单机 AI Provider

- CONFIG-01　在工程版配置 OpenAI 兼容服务地址、模型、API 密钥和超时。保存后立即生效，重启可重新读取。环境变量继续提供初始配置。
- CONFIG-02　连接测试只发送固定探测文本，返回真实连接或协议错误。设置接口不返回密钥，保存时仅同一服务地址可保留原密钥。
- CONFIG-03　备课、整册队列、大纲辅助和学伴共用真实传输。学伴失败时呈现错误。复制现成教材继续作为明确标识的模板操作。
- 验收使用本机协议夹具，覆盖保存、重新读取、密钥不回显、切换地址、配置后即时生成及上游错误。真实外部服务由配置者主动测试。
